# Portfólio - Vila de Pedrinhas, Ilha Comprida/SP

Projeto escolar de uma landing page/portfólio sobre a Vila de Pedrinhas, em Ilha Comprida, São Paulo.

## Arquivos

- `index.html` - estrutura e conteúdo do site. As imagens usadas no projeto estão incorporadas diretamente no HTML para que a pasta não precise de uma subpasta de imagens.
- `style.css` - toda a parte visual e responsiva.
- `PROMPT.pdf` - prompt utilizado no desenvolvimento.

## Como abrir

1. Deixe `index.html` e `style.css` na mesma pasta.
2. Abra o `index.html` no navegador ou use o Live Server no VS Code.

O site foi feito somente com HTML e CSS, sem JavaScript, frameworks, banco de dados ou bibliotecas de interface.
